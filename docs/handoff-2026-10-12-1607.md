## How the loop works

1. `repoos list` for the board; `repoos show <id>` and the activity log for each task.
2. A task in REVIEW with a "good to go" note gets `repoos done <id> --wait`, one at a time.
3. "needs some work" means the engineer must fix the listed items. Read the verdict in `.repoos/agent-logs/review:<id>*.out.log` (grep for `Verdict` and `Blocking`), then `repoos message <id> "..."`. Messages to a busy agent are refused, so retry later. (Known bug: #0756.)
4. A task marked `needs_input` is usually a stalled engineer or a reviewer escalation. Check the reason first.
5. Ask the maintainer only for real decisions (product choices, credentials, signing). Everything else, act on.
