# Roadmap

## Foundation · present

RepoOS initialization, requirements, architecture ADR, performance protocol, static landing/docs website, proposed JSON configurations, and tested native geometry library. No downloadable app.

## 0.1 · useful native bar

1. AppKit app target and display adapter: left/right panels, focus, multiple displays, notch-free fallback, overflow.
2. Provider pipeline and minute clock, power, frontmost app; notifications and cancellation.
3. AeroSpace capabilities/events, workspace indicators and async actions.
4. Versioned config loader, atomic reload, settings, launch at login.
5. Accessibility and appearance; physical device QA and performance evidence.
6. Developer ID signing/notarization and source/build release instructions.

## 0.2 · personal workflows

Additional native status providers, per-display profiles, safe script protocol, reusable themes. Every item remains subject to measured cost and independent failure handling.

## Later

Yabai adapter, optional update mechanism, configuration editor improvements. Private APIs, mirrored menu extras, and a marketplace are not baseline commitments.

Create execution tasks through `repoos new` when the control-plane project is live. The initial inbox vision/setup tasks are suggestions; do not mark them complete because this document exists.
